# For any agent working on SingersVoice

**Before any code change, read the relevant files in `AGENT_MEMORY/` (start with `AGENT_MEMORY/README.md`) and
follow them. Update them in the same change whenever a requirement, a default, a decision or a verification result
changes.** That folder is the project's standing memory: the owner's requirements, the two listening modes
(PERFORMER / PUBLISH) and their levels, the defaults, the workflows, the security constraints, the decisions, the
corrections, and the commands that verify everything.

Nothing is claimed to work until the labs and e2es in `AGENT_MEMORY/verification.md` pass — and, for audio, the
recorded output has been measured.
